## Flagship Project — Scribble

**[scribble.ayushkumarsingh.me](https://scribble.ayushkumarsingh.me)** · Medium-style writing platform · ⚡ *currently building*

<sub>React 18 · Zustand · Node.js · Express · MongoDB · Tailwind CSS</sub>

> *Auth that rotates, webhooks that sign, writes that don't race — every row below was built, not planned.*

| Area | What's built |
|---|---|
| **Auth** | JWT in httpOnly cookies with **refresh-token rotation + SHA-256 reuse detection** · per-device sessions with instant revocation · cross-tab refresh serialized via the **Web Locks API** |
| **Multi-tenancy** | Team workspaces with **backend-enforced RBAC** · fully audited owner-account impersonation · centralized audit middleware logging all successful writes (**90-day TTL trail**, sensitive-field redaction) |
| **Developer platform** | Versioned **public REST API** (API-key Basic Auth) + **HMAC-SHA256 signed webhooks** across **11 events** — SSRF & DNS-rebinding guards, retry with backoff, auto-disable |
| **Concurrency** | Race-safe view/read analytics (**atomic upserts + duplicate-key fallbacks**) · ReDoS & NoSQL-injection-safe unified search with **cancellable type-ahead** · DOMPurify-sanitized **TipTap + Markdown dual editor** |
| **Scale** | **62 REST endpoints · 11 models · 22 explicit indexes (4 TTL)** — strict `routes → validators → controllers → services` layering |
